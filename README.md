# MDC — Modern Discovery Center

A clean, modern, mobile-first homepage designed specifically for **Samsung Internet** (One UI design language).  

Features a prominent search bar with multi-engine support, local history, bookmarks, and theme switching — all stored privately in your browser using `localStorage`.

## Features

- **One UI Inspired Design** — Rounded corners, soft shadows, smooth animations, and clean typography optimized for mobile.
- **Multi-Engine Search** — Instantly switch between Google, Yandex, Bing, and DuckDuckGo.
- **Search History** — View and clear your recent searches (stored locally).
- **Bookmarks** — Save your favorite sites.
- **Dark / Light Mode** — Automatic system preference detection + manual toggle.
- **Quick Links** — Customizable shortcuts below the search bar.
- **Fully Responsive** — Works beautifully on phones, tablets, and desktops.
- **Privacy First** — No tracking, no external requests. Everything stays on your device.

## How to Set as Homepage in Samsung Internet

Follow these steps to make MDC your default homepage:

1. Open the **Samsung Internet** browser.
2. Tap the **Menu** button (three dots or lines) in the bottom-right corner.
3. Tap **Settings**.
4. Select **Homepage**.
5. Choose **Custom**.
6. Paste the deployed URL of this MDC web app (example: `https://yourusername.github.io/mdc/`).
7. Tap **Done** or **Save**.

Now, every time you open a new tab or the browser, MDC will appear as your homepage.

## Tips

- The app automatically remembers your preferred search engine and theme.
- You can clear history or reset all data from the Menu → Settings.
- Works offline after the first load (except for actual searches).
