# MDC — Modern Discovery Center

A clean, modern, mobile-first homepage designed specifically for **Samsung Internet** (One UI design language).  

Features a prominent search bar with multi-engine support, user-managed shortcuts, local history, bookmarks, theme switching, and **One UI version appearance options** — all stored privately in your browser using `localStorage`.

## Features

- **One UI Inspired Design** — Highly rounded elements, soft shadows, blur/frosted effects, clean typography.
- **One UI Version Selector** — Choose One UI 6, 7, 8, or 9 in Settings to adjust corner radius, spacing, and glass effects.
- **Samsung Internet Style** — Standard, Glassy/Frosted, or Compact options.
- **Multi-Engine Search** — Google, Yandex, Bing, DuckDuckGo.
- **User Shortcuts** — Add your own shortcuts with title, URL, and optional emoji icon. Delete by hovering.
- **Search History** — View and clear recent searches.
- **Bookmarks** — Save favorite sites.
- **Dark / Light Mode** — System preference + manual toggle.
- **Fully Responsive** — Optimized for mobile (Samsung Internet).
- **Privacy First** — Everything stays local.

## Deployment

Host as a static site (GitHub Pages recommended):

1. Upload the files to a repository.
2. Enable GitHub Pages from the `main` branch root.
3. Use the resulting URL (e.g. `https://mdcforlegal.github.io/MDC-browser/`) as your homepage.

## How to Set as Homepage in Samsung Internet

1. Open the **Samsung Internet** browser.
2. Tap the **Menu** button (three dots or lines).
3. Tap **Settings**.
4. Select **Homepage**.
5. Choose **Custom**.
6. Paste the deployed URL of this MDC web app.
7. Tap **Done** or **Save**.

## Tips

- Change One UI version and browser style in **Menu → Settings** to match your device.
- Shortcuts are fully user-controlled — no pre-filled ones.
- All data is stored in `localStorage` and can be reset from Settings.
